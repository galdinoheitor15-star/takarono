# Takarono · Site de pedidos

Site do Restaurante Takarono (Carpina-PE). O cliente monta o pedido no cardápio e envia direto para o WhatsApp do restaurante.

- **Cardápio e preços:** edite a lista `CARDAPIO` no início do `<script>` em `index.html`.
- **Logo:** substitua `logo.png` mantendo o mesmo nome.
- **WhatsApp:** constante `WA` em `index.html`.

Endereço: Av. Padre Rocha, 305, Carpina-PE · Seg a Dom, 11h às 23h · [@takaronocarpina](https://instagram.com/takaronocarpina)
